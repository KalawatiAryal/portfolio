# Portfolio Website

A modern portfolio website built with React and Vite.

## Features

- ✨ Modern, responsive design
- ⚡ Built with React 18 and Vite for fast development
- 📱 Mobile-friendly interface
- 🎨 Beautiful gradient design with smooth animations
- 📍 Navigation with smooth scrolling
- 🚀 Ready to deploy

## Project Structure

```
src/
├── pages/
│   └── HomePage.jsx       # Main portfolio page
├── styles/
│   └── HomePage.css       # HomePage styles
├── App.jsx               # Main app component
├── App.css               # App styles
├── index.css             # Global styles
└── main.jsx              # React entry point
```

## Getting Started

### Prerequisites

- Node.js (v20 or higher)
- npm or yarn

### Installation

1. Navigate to the project directory:
```bash
cd Frontend
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build for production
- `npm run preview` - Preview the production build

## Customization

### Update Personal Information

Edit `src/pages/HomePage.jsx` to:
- Change your name and title
- Add your actual projects
- Update contact information and social links

### Styling

All styles are in `src/styles/HomePage.css`. Modify colors, fonts, and layouts to match your preferences.

## Deployment

Build the project for production:
```bash
npm run build
```

The optimized files will be in the `dist` directory, ready to deploy to any static hosting service.
